## Mac

| Target Domain | Key | Value | Purpose |
|---|---|---|---|
| Dock | autohide-time-modifier | 0.2 | Dock自動表示アニメーション速度を高速化 |
| iOS Simulator | ShowSingleTouches | 1 | Simulator上でタッチ位置を可視化 |
| Xcode | ShowBuildOperationDuration | YES | ビルド各工程の実行時間を表示 |
| Dock | show-recents | false | Dockの最近使用アプリ表示を無効化 |
| Global | InitialKeyRepeat | 12 | キー長押し後のリピート開始時間を短縮 |
| Global | KeyRepeat | 1 | キーリピート速度を最大化 |
| QuickTime Player | NSRecentDocumentsLimit | 0 | 最近開いたファイル履歴を保存しない |
| QuickTime Player | RecentDocuments | delete | 最近開いたファイル履歴リストを削除 |
| QuickTime Player | MaxAmount | 0 | 最近のドキュメント保持数を0に制限 |
